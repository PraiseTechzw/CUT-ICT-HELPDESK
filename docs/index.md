# CUT ICT Helpdesk Documentation

This is the documentation home for **CUT ICT Helpdesk**, a role-aware ICT support portal prototype for Chinhoyi University of Technology.

> **Status:** Locally verified development foundation (Phases 1–5). It is **not** an approved production deployment. CUT ICT must still confirm identity, roles, privacy, retention, branding, hosting, database, email, accessibility and operational policy before live use. See [Project scope](PROJECT_SCOPE.md) and [Requirements and open questions](REQUIREMENTS_AND_OPEN_QUESTIONS.md).
